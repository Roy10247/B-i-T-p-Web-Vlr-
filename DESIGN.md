## Brand & Style

The design system embodies a high-stakes, competitive, and covert tactical operations aesthetic. Built for players, esports enthusiasts, and prospective agents, the interface conveys precision, military-grade telemetry, and kinetic energy. Every visual element evokes a high-tech tactical HUD: stripped of decorative excess, hyper-focused on function, and razor-sharp in execution.

The style fuses High-Contrast Brutalism and Tactical Sci-Fi HUD architecture:
- **Military Precision:** Corner brackets, targeting reticles, coordinate readouts, and monospaced diagnostic markers ground the interface in an operational reality.
- **Aggressive Geometries:** Chamfered 45-degree cut corners, diagonal slash dividers, and asymmetric structural offsets break standard web conventions.
- **Cybernetic Contrast:** Deep stealth tones paired with saturated radiant signals (tactical red and electric cyan) create immediate visual urgency.
- **Atmospheric Textures:** Faint phosphor scanlines, micro dot-grids, and tactical telemetry watermark overlays generate depth without sacrificing read performance.

## Colors

The palette establishes an aggressive combat environment balanced by operational legibility:

- **Primary (`#FF4655` / Radiant Red):** High-priority calls-to-action, active agent telemetry, critical system warnings, and combat badges.
- **Secondary (`#00F0FF` / Hyper Cyan):** Secondary interactive nodes, shielding markers, technical specs, network telemetry, and tactical highlight states.
- **Tertiary (`#768079` / Muted Slate):** Coordinate stamps, grid ticks, inactive boundary lines, and technical metadata.
- **Neutral Canvas (`#0B1116` to `#0F1923` / Deep Charcoal & Black):** Layered background depths that absorb light and allow high-energy accents to pop.
- **High-Key Contrast (`#ECE8E1` / Off-White):** Dominant readable text, headline fills, and primary structural edges.

### Semantic Tones & Accents
- **Surface Level 0 (Void):** `#0B1116` — Page canvas base.
- **Surface Level 1 (Chassis):** `#0F1923` — Modules, containment panels, and cards.
- **Surface Level 2 (Bunker):** `#1A252F` — Hover states, nested trays, and secondary inputs.
- **Border / Structural Grid:** `#273644` with intermittent 1px accents in `#FF4655` or `#00F0FF`.
- **Text Primary:** `#ECE8E1` (High-contrast tactical white).
- **Text Secondary:** `#768079` (Telemetry grey).

## Typography

Typography functions as both raw data display and weaponized brand expression:

- **Display & Headlines (`Oswald`):** Always uppercase, tightly kerned, condensed, and architectural. Headings mimic military signage and operational status monitors.
- **Body Text (`Space Grotesk`):** Clean, structural grotesque with open apertures for razor-sharp legibility at small sizes against dark backdrops.
- **Technical Telemetry & Labels (`Space Mono`):** Monospaced, letter-spaced, and mechanical. Applied to badges, spatial coordinates, system flags, and numeric attributes.

All primary headlines (`headline-lg` and up) should incorporate index prefixes (e.g., `// 01. INTEL`, `PROTOCOL // DEFUSE`) set in `Space Mono` directly above or inline with the Oswald heading.

## Layout & Spacing

The layout is constructed on a 12-column rigid tactical grid with intentional asymmetric offsets, deliberate negative space, and visible reference lines.

### Grid Structure & Breakpoints
- **Desktop (1280px+):** 12 columns, 1.5rem (`24px`) gutters, 3rem (`48px`) margins. Full telemetry indicators, tactical corner lines, and vertical ruler lines flanking the edges.
- **Tablet (768px – 1279px):** 8 columns, 1rem (`16px`) gutters, 2rem (`32px`) margins. Minor coordinate overlays drop off; structural cutouts remain intact.
- **Mobile (Below 768px):** 4 columns, 0.75rem (`12px`) gutters, 1rem (`16px`) margins. UI modules collapse to stacked combat trays.

### Sectioning & Construction
Sections are demarcated by hard 1px rule boundaries (`#273644`) with chamfered cut breaks, crosshairs at grid intersections (`+` marks), and numbered tactical coordinates (`[LAT // 35.6895° N]`). Layouts avoid soft transitions in favor of crisp, structural block-to-block boundaries.

## Elevation & Depth

Tactical systems do not use diffused, organic drop shadows. Depth is achieved via hard layers, neon radiance, and crisp framing:

- **Layer 0 (Canvas):** `#0B1116` base covered by an ultra-subtle repeating horizontal scanline pattern (1px transparent black lines every 3px) and an optional 32px isometric dot-matrix overlay at 4% opacity.
- **Layer 1 (Tactical Frame / Container):** Flat `#0F1923` panel bordered by 1px `#273644`. Elevated state is communicated by a hard 2px offset border in `#FF4655` or `#00F0FF` without blur.
- **Radiant Overcharge (Active / Critical):** When an element activates or enters a critical focus state, it casts an intense, condensed directional neon glow:
  - *Red Focus:* `0 0 16px rgba(255, 70, 85, 0.45), 0 0 3px #FF4655`
  - *Cyan Focus:* `0 0 16px rgba(0, 240, 255, 0.45), 0 0 3px #00F0FF`
- **Ghost Cutouts:** Floating tactical panels feature backdrop blur (`backdrop-filter: blur(12px)`) at 85% opacity `#0F1923` with 4 corner brackets drawn via CSS or SVG borders.

## Shapes

The geometric vocabulary is uncompromising: zero rounded radii (`0px`). Rounded corners are forbidden throughout the system.

- **Chamfered Cuts (Angled Corners):** Interactive surfaces and hero modules use 45-degree angled cuts implemented via `clip-path: polygon(...)`. The default chamfer cut is `12px` on the top-right and bottom-left opposing corners.
- **Bracket Motifs:** Panels without chamfered cuts use open corner brackets (4px horizontal and vertical 1px/2px tactical ticks) framing the content area.
- **Divider Cuts:** Horizontal dividers use asymmetric slash notches (`/ / / /`) or 45-degree wedge steps.

## Components

### Buttons
- **Primary Tactical CTA:** Background `#FF4655`, text `#ECE8E1` in `Oswald` bold uppercase. Top-right corner cut with `12px` chamfer. A pseudo-element slash accent (`//`) on the left edge. Hover state: background transforms to `#ECE8E1`, text snaps to `#0F1923`, accompanied by an instant neon perimeter ping.
- **Secondary Protocol Button:** Transparent background, 1px border `#ECE8E1` or `#00F0FF`, text in matching tone. Opposite corner cuts (top-left, bottom-right). Hover state: solid fill of border color with inverted text.
- **Ghost Command Button:** Monospaced `Space Mono` with bracket framing (`[ DEPLOY AGENT ]`), colored `#768079`. Hover: shifts to `#00F0FF` with a subtle cursor blinking underscore.

### Chips & Badges
- **Status Badges:** Strict rectangular tags with 1px border. Feature an 8px square blinking live-status indicator dot (red or cyan). Monospace typography (`Space Mono`, uppercase, letter-spacing `0.14em`).
- **Agent Role Badges (Duelist, Initiator, etc.):** Inverted slate backgrounds (`#1A252F`) with a 45-degree angled left edge, topped with an electric cyan accent stripe.

### Cards & Dossiers
- Chamfered containers (`#0F1923`) with 1px border `#273644`.
- Integrated HUD top-bar displaying module serial code (`SEC-08 // VAL`), status ping, and an minimize/expand glyph.
- The perimeter houses 4 tactical corner ticks. Hover elevates the border to `#FF4655` with an instant mechanical shift (2px upward translation, zero ease curve).

### Input Fields
- Dark canvas fill (`#0B1116`) enclosed by a bottom 2px rule `#768079` and 1px muted side borders.
- Floating monospaced label with index format: `01 // ENTER RIOT ID`.
- Focus state: bottom rule ignites to `#00F0FF` with a cyan corner flash, typing text in `#ECE8E1`.

### Checkboxes & Radios
- **Checkbox:** `16px` pure square, 1px `#768079` border. Checked: filled `#FF4655` with a sharp diagonal slash across the square instead of a soft checkmark.
- **Radio Button:** Diamond-shaped container (square rotated 45 degrees). Checked: nested solid diamond in `#00F0FF`.

### Lists & Telemetry Tickers
- Bullet points replaced with directional tactical carets (`>`) or monospaced numbers (`01`, `02`).
- Items separated by subtle 1px dashed borders `#273644`. Hover highlights the entire row with a 2% off-white wash and a 2px left border strip in `#FF4655`.

### Tactical HUD Reticles & Overlays (Specialty)
- Crosshair targets positioned over agent media cards.
- Coordinate watermarks (`34°01'08.2"N 118°28'38.4"W`) rendered in `Space Mono` at 10px, oriented vertically along layout gutters.
